# Ledger Service

Это простой сервис для ведения личного бюджета, разработанный в рамках изучения языка программирования Go. Проект демонстрирует базовые принципы работы с структурами, методами, JSON, а также применение интерфейсов для реализации полиморфизма и разделения ответственности.

## Основные возможности

*   **Учет транзакций**: Добавление финансовых операций (доходов/расходов).
*   **Бюджетирование**: Установка лимитов трат по различным категориям.
*   **Валидация данных**: Встроенная проверка корректности транзакций и бюджетов перед их добавлением в систему.
*   **Проверка бюджета**: Система не позволяет добавить транзакцию, если она превышает установленный лимит по категории.
*   **Загрузка бюджетов из файла**: Возможность загрузки стартовых бюджетов из `budgets.json`.
